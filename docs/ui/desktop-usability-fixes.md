# 桌面 UI/UX 修复清单（dev）

基于 `dev` 分支 `9aa616721d91362f01b944f178b2f8dcc899703a`。

范围：项目首页、工作区文件页、对话输入区、Memory 和设置。沿用 dev 分支的紧凑 Memory 卡片，不进行手机端重设计。

| 问题 | 修复方法 |
| --- | --- |
| 首页概览区占用过多首屏空间，操作图标并列且容易误触 | 合并为最近项目入口和简要统计；重命名、删除收进更多菜单，保留固定和任务入口。 |
| Memory 页头、内容宽度和控件风格与工作区不一致 | 使用共享 WorkspacePage/Header、按钮和输入框样式；明确主操作，保留紧凑列表。 |
| Memory 管理功能挤占浏览区 | 将项目召回和分类管理集中到独立管理弹窗。 |
| 文件加载失败被误认为空目录；Memory 失败时数量误显示为零 | 加入持续可见的错误状态和重试；区分加载、失败、空数据与旧数据；失败的数量显示不可用。 |
| 文件删除按钮仅悬停可见，长文件名难读，整行点击反馈不匹配 | 删除按钮常显并支持键盘焦点；名称换行；打开按钮覆盖主要行区域；增加名称搜索、排序和修改日期。 |
| 对话中的模型错误、审查提示字号小且被截断 | 提示独立展示并换行；模型错误提供设置入口。 |
| 引用只能鼠标点击、附件移除缺少可访问名称 | 引用插入改为按钮；补全中英文操作名称；插入后恢复输入框焦点。 |
| Memory 正文字号偏小 | 摘要使用 13px，展开正文使用 14px，保持已有卡片密度。 |
| 原生确认框与应用风格不一致，嵌套弹窗的层级和焦点不统一 | 统一 Radix 确认弹窗、焦点约束和恢复；Escape 仅取消顶层确认；危险操作默认聚焦取消。 |
| 长设置页保存入口难找，切换页签丢失草稿 | 底部吸附保存栏；页签及弹窗切换保留会话草稿；显示未保存状态，支持主动丢弃；无修改时禁用保存。 |
| 通用设置的作用域说明误导，导航名称被截断 | 通用偏好标明当前设备；保留 Memory 的全局说明；导航文字允许换行。 |
| “Run history”、Dream 等术语不易区分，焦点样式较弱 | Memory 改称记忆任务，补充整理/审核解释；统一实线高可见焦点轮廓。 |
| 视觉测试模型接口落后于 dev，Linux 桌面截图缺失 | 更新 native model-config 测试夹具和断言；补充桌面截图与失败重试、草稿、键盘和嵌套确认验收。 |

设计参数与提案见 [设计基准](deepseek-harness-reference.md)。

- 完整前端单元测试：189 个文件、1,864 项全部通过。

- 最终构建再次通过 12 项桌面交互验收：错误与空状态区分、重试、键盘操作、草稿保留、保存栏可见性、嵌套确认焦点和 Escape。

- `git diff --check` 通过。
