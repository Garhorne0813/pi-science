# 设置页一致性调整

基于 PR #222 (`41d0a283`)。

- 通用与外观包含设备偏好及进度外观；进度外观单独标明全局作用域与自动保存。
- 移除独立能力与进度导航，保留旧入口重定向。子代理归入 Agent，内置能力与文件示例收进说明。
- 模型服务、默认模型、审批、上下文压缩使用全局设置说明；子代理明确来自当前项目。
- 压缩关闭后隐藏阈值与预览，保存入口始终保留。Memory 沿用分层开关，整理运行条件收进高级区；这些限制也适用于手动运行，不能按手动模式直接隐藏。
- 搜索和读取共用供应商配置（DeepSeek 也用于读取），仅两项均关闭时折叠供应商。关闭时保留配置。删除密钥仅提交密钥补丁，不保存其他草稿。
- 动效关闭后隐藏速度与动画图案，保留静态颜色偏好。
- 统一开关、下拉菜单、卡片标题和配置保存栏。Agent 后端接口独立，使用明确的“保存默认模型”和“保存上下文设置”，不伪装为原子事务。
- 已访问的标签页在设置打开期间保留挂载，切换标签保留草稿。键盘焦点循环排除隐藏标签与折叠内容。Memory 继续使用原有会话草稿；其他草稿不写入浏览器持久存储，关闭设置即释放。

验收覆盖：条件展示、关闭后参数保留、独立密钥删除、失败重试、标签切换草稿、隐藏控件焦点过滤、浅色/深色及窄桌面布局与可访问性。
