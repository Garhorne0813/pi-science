# Pi-Science demos

The demos are self-contained workspace seeds. Install one from the Projects
page or copy a demo directory into a workspace to explore a specific workflow.

| Demo | Focus |
|------|-------|
| [`climate-trends`](climate-trends/) | CSV analysis, plotting, notebooks, and artifact provenance |
| [`molecular-playground`](molecular-playground/) | Molecular viewers, structure files, drug-likeness, and literature search |

Keep demo data and helper scripts inside the relevant demo directory. The
application source tree should not contain demo-only Python files or datasets.
